The page counts **Call tapped**, **Email tapped** and **Enquiry sent**. Pageviews
are vanity. To switch the counting on (5 min, free):

1. dash.cloudflare.com → Analytics → Web Analytics → Add a site
2. Enter https://enocherdner.github.io/the-cleaning-queen/, copy the `<script>` tag
3. Paste it in `index.html` where it says `ANALYTICS TAG GOES HERE`
4. Republish

Until that is done, enquiries are countable (they arrive by email) but call taps
are not. Do not promise a call-tap number before switching it on.
